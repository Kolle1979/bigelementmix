# Mitmachen bei BigElementMix

Danke für dein Interesse an BigElementMix. Das Projekt ist ein kostenloses Hobbyprojekt.

## Ideen und Fehler melden

Öffne ein Issue und beschreibe:

1. Was du erwartest hast.
2. Was stattdessen passiert ist.
3. Gerät, Browser und Betriebssystem.
4. Schritte zur Wiederholung.
5. Screenshots oder Videos, falls hilfreich.

## Änderungen vorschlagen

1. Forke das Repository.
2. Erstelle einen eigenen Branch.
3. Ändere möglichst nur eine Funktion.
4. Prüfe die Änderung selbst.
5. Erstelle einen Pull Request mit klarer Beschreibung.

## Regeln

- Keine Zugangsdaten, privaten Daten oder Geheimnisse einreichen.
- Keine fremden Bilder, Musik, Schriften oder Code ohne klare Nutzungsrechte.
- Keine schädlichen Funktionen, Tracker oder unnötige externe Verbindungen.
- Keine direkten Änderungen an der offiziellen Live-Version.
- Die Veröffentlichung entscheidet der Projektbetreiber.

## Testen

Jede Änderung sollte mindestens diese Prüfungen bestehen:

- Spiel startet ohne JavaScript-Fehler.
- Malen, Radieren und Pause funktionieren.
- Speichern und Laden funktionieren.
- Bestehende Elemente und Szenen bleiben nutzbar.
- Auf Desktop und Mobilgerät ist die Bedienung möglich.
